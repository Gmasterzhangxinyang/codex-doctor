# Changelog

## 0.4.0

- Reposition Codex Doctor as a one-shot Codex session health check.
- Make `codex-doctor` run the default health check without a subcommand.
- Add `python -m codex_doctor` as a fallback module entry point.
- Save the user's preferred language during `codex-doctor install`.
- Print visible evidence before conservative interpretation.
- Remove the main-product focus on background notification and dashboard workflows.

## 0.1.0

- Initial MVP scaffold for local Codex diagnostics.
- Added hook recording, local storage, redaction, state classification, OpenAI network probing, reports, and optional plugin files.
